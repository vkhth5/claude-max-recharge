## 代充不是一件事：先分清你要买的是哪一类

**卡充（直充、续费）**：充进你自己已有的账号。你把账号的登录凭证（Session / Cookie）交给平台，它用自己手上的支付通道替你完成订阅。账号还是你的，聊天记录、Projects 都在。代价是你要信任对方拿到凭证后不会乱来，而且一旦官方风控封号，锅不在平台那边。

**成品号**：平台给你一个已经开好订阅的账号。便宜、到手即用，但账号注册信息、邮箱、恢复方式都在别人手里。哪天被找回，你手里的东西就是零。

**拼车 / 共享号**：几个人凑一份 Max，轮流用或者共用一套凭证。这是闲鱼上最常见的形态，也是封得最快的——一篇 LINUX DO 的晒单帖里，有人拼的 Max 20x 一天就没了，400 多块钱连个回头路都找不到。

**请求转发型**：不碰你的账号，而是把请求转到他们自己的出口。封号风险相对低，但溢价高，而且你的对话内容在中间过一手。

知道自己在买哪一种，很多后面的判断就不用别人替你做。

## 下单前必须接受的几个风险

**封号不是平台能担保的事。** 第三方代付订阅本身处在 Anthropic 服务条款的灰色地带，加上 Session 凭证的授权方式和使用时的 IP 环境，封号原因往往说不清是哪一环触发的。有商家直接在商品页写明"保订阅不等于保账号不被封"，这个表述是诚实的。

**退款口径各家不同，社区说法也不一致。** 同一个讨论串里，有用户称封号后退款成功、只扣了一点手续费；也有用户说平台只在官方退款到账后才退还，官方不退就不垫付；还有人提到退款要扣 25% 手续费。这三种说法互相矛盾，我无法核实哪个是当前有效的条款。**唯一可靠的做法是在付款前把退款条款截图问客服，让对方明确回答"封号但不退款时怎么办"。**

**库存会断。** 2026 年 9 月前后，就有用户反馈 BeWild 的 Claude 相关商品全部显示售罄。Claude 的通道比 ChatGPT 更容易出问题，充不进去的情况平台一般会走退款，但你的时间成本回不来。

**KYC 会拦人。** 未完成身份验证的账号可能充不进去，需要先走一遍 Anthropic 的验证流程。世事宜AI 按 KYC 状态分开定价，说明这是行业的普遍问题而不是个别现象。

**前身的历史要算进去。** 野卡时期有用户反映余额损失，这是平台的信用记录，不是已解决的旧闻。

## 什么情况下不该走代充

有稳定的海外信用卡，或者 App Store / Google Play 账号能正常内购：直接官方订阅，少一层中间商，省下的钱不见得比风险溢价低。

只是偶尔用：免费版够用就别折腾。Max 的额度是给每天跑 Claude Code、动辄几小时长任务的开发者准备的，不是给每周问几个问题的人。

需要发票、对公采购、合规留痕：先确认平台能不能开票。这一点上，明确写了"支持开票、对公采购"的商家反而更好判断。

纯看价格：那你要接受地区套利那套玩法带来的封号概率，而且基本没有售后。

**Claude Max 5x 和 20x 该怎么选？**

**代充会看到我的密码吗？**
BeWild 这类走 Session 授权的平台拿不到你的密码，但 Session 凭证在有效期内等同于登录态，所以授权前最好确认自己登录的是官方域名，别在第三方页面填 Claude 账号密码。

**充完之后账号还会自动续费吗？**
平台卖的是固定月份，到期需要手动再买。对怕忘记取消被扣款的人来说是好事，对懒得管的人就是个坑。

**为什么不用官方渠道？**
能用就用。代充存在的唯一理由是支付门槛，不是产品本身更好。
